# ChrisJack.com — Version 2: Real Artwork Edition

This is a static site ready for GitHub Pages. Includes 26 selected artworks and the original 34-second taco video.

## Preview
Open `index.html` in your browser. The artwork, filtering and lightbox work without a web server.

## Publish to existing GitHub Pages repository
Upload the **contents** of this folder (`index.html`, `styles.css`, `script.js`, `gallery.json`, and the `assets/` directory) to the root of your existing `RealSatyrday/chrisjack-site` repository. Commit changes. GitHub Pages should then serve the new site on your configured domain.

## Notes
- No placeholder images or fictional testimonials.
- Contact email intentionally omitted until confirmed.
- The video is included locally, so it plays from your site.
- The original art files were resized/compressed for web delivery; preserve your masters separately.
- `gallery.json` lists artworks and categories for future curation.
- The restoration image is a working-process example, not a final before/after presentation.
- External Google Fonts are optional; fallback fonts work offline.
